================================================================================
                            WINDOWS SETUP
================================================================================

📋 PREREQUISITES:
- Windows 10/11 (64-bit)
- Docker Desktop for Windows
- 4GB+ RAM available
- 2GB+ free disk space

🔧 STEP 1: INSTALL DOCKER DESKTOP
1. Download Docker Desktop from: https://www.docker.com/products/docker-desktop/
2. Install and restart your computer
3. Start Docker Desktop and wait for it to fully load
4. Verify installation by opening Command Prompt and running:
   docker --version

📁 STEP 2: EXTRACT THE DOCKER IMAGE
Option A - Using 7-Zip (Recommended):
1. Download 7-Zip from: https://7-zip.org/
2. Right-click on "automan-client-universal.tar.gz"
3. Select "7-Zip" → "Extract Here"
4. You'll get "automan-client-universal.tar"

Option B - Using Windows Terminal:
1. Open PowerShell as Administrator
2. Navigate to the package folder:
   cd "C:\path\to\client-delivery-package-final"
3. Extract the file:
   tar -xzf automan-client-universal.tar.gz

🚀 STEP 3: LOAD AND RUN THE APPLICATION
1. Open Command Prompt or PowerShell
2. Navigate to the package folder:
   cd "C:\path\to\client-delivery-package-final"
3. Load the Docker image:
   docker load -i automan-client-universal.tar
4. Verify the image loaded:
   docker images
5. Run the application:
   docker run -p 8080:8080 automan-client:universal

🌐 STEP 4: ACCESS THE APPLICATION
1. Open your web browser (Chrome, Firefox, Edge)
2. Go to: http://localhost:8080
3. Login with:
   - Email: admin@gmail.com
   - Password: Admin#12
4. Click "Sign In"

🔧 WINDOWS TROUBLESHOOTING:
- "Docker Desktop is not running": Start Docker Desktop and wait for full load
- "Port is already allocated": Try different ports (3000, 5000, 9000)
- "Cannot extract .tar.gz": Install 7-Zip or use WSL
- "Network error during login": Wait 5-6 minutes for full startup

================================================================================
                            UNIVERSAL TROUBLESHOOTING
================================================================================

🚨 COMMON ISSUES AND SOLUTIONS:

1. PLATFORM ARCHITECTURE WARNING:
   Warning: "linux/arm64 does not match linux/amd64"
   Solution: Use the correct image for your platform:
   - Windows/Intel Mac: docker run -p 8080:8080 automan-client:amd64-fixed
   - Apple Silicon Mac: docker run -p 8080:8080 automan-client:universal

2. LOGIN FAILURES:
   - Wait 5-6 minutes for full startup
   - Check container logs: docker logs <container_id>
   - Verify admin user exists in database
   - Try refreshing the browser page

3. PORT CONFLICTS:
   - Try different ports: 3000, 5000, 9000
   - Check what's using port 8080: netstat -ano | findstr :8080 (Windows)
   - Check what's using port 8080: lsof -i :8080 (Mac)

4. DOCKER ISSUES:
   - Restart Docker Desktop
   - Check Docker Desktop is running
   - Verify Docker has enough resources (4GB+ RAM)
